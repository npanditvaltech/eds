# tabs-cards

Custom **tabs** block. Purpose: tab menu whose panels each render a grid of linked article cards.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tab: cell 1 tab label; cell 2 repeated cards, each authored as image, tag paragraph, H3 heading containing the article link, short description.

## Supported variations

No variations.
