# cards-ticker

Custom **cards** block. Purpose: auto-scrolling horizontal marquee of text labels with dot separators.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per label, one cell of plain text. Author each label once; the block duplicates them for the loop and adds the separators.

## Supported variations

No variations.
